# Импорт резюме с компьютера в Bitrix24

Инструмент находит PDF и DOCX в выбранных папках, извлекает данные кандидатов через сервер Imena.kz, формирует отчёт и после отдельного подтверждения создаёт или обновляет контакты типа «Кандидат» в Bitrix24.

## Безопасный анализ без загрузки

Откройте PowerShell в папке проекта и запустите:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\import-resumes.ps1
```

По умолчанию проверяются «Загрузки», «Документы» и «Рабочий стол». Результат сохраняется в `imena-resume-import-report.csv`. На этом этапе Bitrix24 не изменяется.

## Выбрать отдельные папки

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\import-resumes.ps1 -Folders "C:\Резюме","D:\Кандидаты"
```

## Загрузка в Bitrix24

После проверки отчёта:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\import-resumes.ps1 -Folders "C:\Резюме","D:\Кандидаты" -Upload -ConfirmDataRights
```

Параметр `-ConfirmDataRights` подтверждает, что у владельца базы есть законное основание для обработки и переноса персональных данных кандидатов.

## Правила

- Поддерживаются PDF и DOCX до 4 МБ.
- Системные и технические папки исключаются.
- Дубли проверяются по телефону и e-mail.
- Контакты клиентов не преобразуются в кандидатов.
- К каждому контакту прикрепляется исходный файл.
- Файлы с недостаточными данными попадают в отчёт с описанием ошибки.
